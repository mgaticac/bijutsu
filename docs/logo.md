# Logo incorporado

Archivo usado por el sitio: `static/img/bijutsu-logo.png`.

Fuente: imagen de referencia adjuntada por el propietario de Bijutsu Printing. Se utilizó la habilidad `imagegen` con la herramienta integrada de edición de imágenes, sin llamadas a una API externa mediante CLI.

Edición solicitada: conservar el símbolo angular BP, el cabezal, la pincelada circular roja/negra y las palabras BIJUTSU PRINTING. Quitar «04», «ESTILO JAPONÉS» y el marco rectangular. Mantener fondo marfil. La salida es una versión raster limpiada con IA, no un archivo vectorial original.

Prompt enviado:

> Edit target: the user's attached BIJUTSU PRINTING logo. Precise identity-preserving cleanup for a website asset. Keep the exact existing central black BP angular 3D printer monogram, the small red/black print head, the irregular red/fuchsia and black circular brushstroke, and especially the exact brush lettering BIJUTSU and spaced PRINTING lettering. Remove ONLY the small '04' in upper left, the small bottom caption 'ESTILO JAPONÉS', and the rectangular black outer border. Preserve all other composition, typography, shapes, relative positions, and ink texture with the highest fidelity possible. No redesign, no new text or slogan. Plain warm ivory background #F5F2EC, square composition, tightly but safely framed with a little breathing space around the circular ink stroke and logo letters. Output one clean high-resolution logo PNG for use on the website. Save the resulting image as a local file and return its path.

El logotipo mantiene sus letras dentro de la imagen. Los titulares de la web utilizan Knewave como fuente complementaria de trazo grueso; no se afirma que sea la tipografía exacta del logo. Está alojada localmente en `static/fonts/`, junto con su licencia SIL Open Font License.
